# Продуктивність

Заміри Lighthouse 13.5.0 на телефоні (емуляція Moto G Power, симульований повільний 4G — налаштування Lighthouse за замовчуванням), Chromium з Playwright, production-збірка через `wrangler dev`. Команда: `npm run build && npm run perf -- / /lesson/<slug>`.

Цілі (SPEC 15): Performance ≥ 85, Accessibility ≥ 90, CLS ≤ 0,05 на головній і сторінці уроку.

- CSS: **370 КБ → 36 КБ** (gzip 42 → 6,8 КБ) — лише базові стилі Mantine і `Skeleton`.

- JS не змінився (≈ 126 КБ gzip): React, роутер, Mantine core. Код-сплітинг маршрутів — разом з екранами уроку (крок 5).

Локальний Supabase з демо-змістом (`npm run seed`), той самий профіль телефона.

Що зроблено по ходу:
- **Головний чанк** 757 → 427 КБ (222 → 133 КБ gzip): `supabase-js` (55 КБ gzip) вантажиться лише при першому запиті, zod-схема знімка — разом зі сторінкою уроку, рушій завдань і блоки — окремими чанками маршрутів.
- **CLS тренування 0,222 → 0**: зсув давала пізня підміна Golos 600/700 — fallback для жирних накреслень тепер з метриками Arial Bold / Roboto Bold, Golos 600 (заголовки, кнопки) — у `preload`; у скелетоні тренування — рядок фільтрів тієї ж висоти.
- Завдання тренування вкладено в запит знімка уроку — на один мережевий обмін менше.

Резерв: LCP уроку ≈ 3,5–4 с на повільному 4G — ланцюжок «чанк маршруту → клієнт Supabase → запит знімка → медіа». Наступні кроки за потреби: почати завантаження клієнта Supabase паралельно з чанком маршруту, кешувати опубліковані уроки в PWA (Фаза 8).

## Фаза 2 — акаунти (14.10.2026)

- **Головний чанк** 427 → 440 КБ (133 → 138 КБ gzip): сесія (`api/auth.ts`), ім'я учня на головній, корінь з «Спрощеним режимом» від вчителя. Гість без збереженої сесії `supabase-js` на головній, як і раніше, не вантажить — перевіряється лише ключ у localStorage.
- Форма входу (zod + React Hook Form) — окремий чанк `LoginRoute` (≈ 2 КБ gzip + спільні zod/RHF); без цього головний чанк зростав до 179 КБ gzip.
- Кабінет вчителя — чанк `TeacherRoutes` (≈ 18 КБ gzip), SheetJS — окремий чанк `xlsx` (≈ 160 КБ gzip), вантажиться лише при виборі файлу .xlsx/.xls у майстрі імпорту. Учні їх не вантажать.

## Фаза 3 · 3.4 — форматований текст (30.10.2026)

- Tiptap + `@mantine/tiptap` — лише в чанку кабінету вчителя (`TeacherRoutes` ≈ 224 КБ gzip разом із ProseMirror); учні його не вантажать (перевірено мережею на `/` і `/lesson/…`).
- Головна вантажить той самий обсяг, що й раніше (≈ 441 КБ, 138 КБ gzip), але двома файлами (`index` + `router`): Rollup виділив спільний з кабінетом код роутера в окремий чанк.
