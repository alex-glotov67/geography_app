# Продуктивність

Заміри Lighthouse 13.5.0 на телефоні (емуляція Moto G Power, симульований повільний 4G — налаштування Lighthouse за замовчуванням), Chromium з Playwright, production-збірка через `wrangler dev`. Команда: `npm run build && npm run perf -- / /lesson/<slug>`.

Цілі (SPEC 15): Performance ≥ 85, Accessibility ≥ 90, CLS ≤ 0,05 на головній і сторінці уроку.
