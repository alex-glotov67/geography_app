# Дизайн «Географія 6–9» — макети для розробки

Ця папка — затверджені макети з полотна дизайну. Поклади її в репозиторій як `docs/design/`.

## Що тут
- `screens/*.dc.html` — вихідний код кожного екрана (макет).
- `canvas.json` — розміщення екранів на полотні і їхні назви (поле `title`, сторінка `page`).
- `tokens.css` — кольори, шрифти, радіуси (те саме, що розділ 13 SPEC.md).

## Як читати файли макетів (для ШІ-агента)
- Це **еталон вигляду**, а не робочий код. Його не підключати в застосунок, а відтворювати компонентами React + Mantine за SPEC.md.
- Розмітка — звичайний HTML з інлайн-стилями: розміри, відступи, кольори, шрифти беруться звідти.
- `{{назва}}` — підстановка значення з блоку `<script type="text/x-dc">` унизу файлу (метод `renderVals()`); там же демо-дані й поведінка (стан, кліки).
- `<sc-for list=…>` — повтор елемента для кожного запису списку; `<sc-if value=…>` — показ за умовою.
- `<script src="./support.js">` і `<x-dc>` — службове середовище полотна, ігнорувати.
- Демо-дані (імена учнів, теми, бали, дати, паролі) вигадані — не переносити в продукт.
- Розбіжність між макетом і SPEC.md → питання вчителю; за замовчуванням пріоритет у SPEC.md.
